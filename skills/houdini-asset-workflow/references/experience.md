# 如何维护经验

这里保存跨实例可复用的方法。当前工程状态、绝对路径、PID、未确认尺寸放专项状态；原始日志/图片放证据。不要把这些内容复制到宿主全局记忆或堆入SKILL入口。

经验条目至少回答：适用于什么、观察到什么、采取什么方法、在哪个版本/样例验证、什么情况下不能照搬。一次失败先作为案例，修复并复测后再推荐；未经运行的想法标为待验证。

用户批准的本次资产/MCP增量完成时，可以整理该范围内的实测经验。以后若要修改Skill规则或扩展适用范围，遵守用户当时的授权；本Skill本身不授予自动发布、安装或修改其他规则的权限。

有新反例时修订原条目、保留证据去向，避免追加一条相反的“最新规则”。优先具体、小幅纠正，不把特定版本的一次问题升级成所有任务的硬限制。

可用格式：

> 条件与版本 → 现象 → 原因/仍未知部分 → 已验证处理 → 样例与证据 → 适用边界。
