# 照片参考变体与局部核对

适用0.10的pipe_rack_reference。先读原照片和用户纠正，不只沿用上轮样段。现有照片为斜仰视、无标尺，能够支持形体/相邻关系观察，不能推出精确管径、截面标准或被遮挡的连接。原图及本次差异清单保留本地交付，源码仓库不上传用户照片。

## 先辨认构造，再选增量

2026-09-21照片复核案例：原模板几何通过，但红管外抱接头仍被同一法兰模板代替。先用构件ID及图中区域建立“可见特征／用户明确要求／工作解释／未知遮挡”，再与当前模型对比。用户要求U形开口向下是明确输入；隐藏螺母、孔距和型号并不随之成为照片已知事实。

斜仰视时按连续构件、所跨管道及固定点推断局部轴，不按屏幕竖直/斜向直接命名世界竖杆。投影交叉不证明已连接；横担与上方构件的遮挡交会，应保留待确认端口，不能自动补角码后宣布现场结构复原。

管道连接链（管A—接头—管B）与支撑链（管外壁—U件—横担—上方宿主）分别核查；邻近法兰不等于U件夹在法兰上。类似厂家资料只支持构造类比，不能确定照片产品或直接套用尺寸。蓝色组件未识别时保留描述性名称。

本例下一增量先验证一个外抱接头和两短管，再发展多接头列表。数值参数接口不因接受dict就支持数组；当前catalog的structured_inputs=false，任意execute_code也不代表已有受管理装配API。保留已有part_names聚焦能力即可。具体源码依据、可复用验收方向及未实施边界见[照片理解案例](../../../docs/PHOTO-READING-CASE.md)。这些是本次分析所得的实施安排，尚未证明外抱接头建模成功，不推广成所有照片任务固定顺序。

## 0.10已实现与已验证经验

0.11接续：[外抱接头独立样件](external-coupling.md)已完成生成及实测。上节“先单接头后列表”的第一项已执行，原pipe_rack_reference仍保留法兰模板，不能把新样件通过写成整组三管已替换。

0.9通用三管样例中的非零rise实心承托块没有照片依据。0.10照片变体默认全部rise=0，黑管同径；这些仍是可调解释，并非证明原图全部同标高。保留旧通用配方便于对照，不隐式覆盖旧HDA。

照片蓝色构件呈现为银色连接面之间有厚度的本体；不要把整块法兰涂蓝就当成还原。新变体使用银法兰夹厚蓝体的外形，未识别厂家/型号/内部功能。红管橙色外抱件仍未完成，不能把它误称为同一蓝色法兰组件。每管当前只有一处接头。

joint_offset_i移动该管接头、紧固件和内侧管端，外侧端点不动；照片中错开的接头不必强行全部X=0。检查实际蓝体厚度、法兰/管端接触和螺栓跨度。移动接头可能碰到支撑站；preflight会在配方校验阶段拒绝，catalog.validation_notes说明此非线性检查。不要把字段范围内数值当成任意组合都可用。

0.10的preview_asset_views增加part_names：从inspect结果取1–128个精确名称，再隔离一个支撑站或一个管道接头。与part_types并用取交集；空交集、空名单、未知名称报错。结果附名称/局部bbox，检查范围确实缩小，随后实际看图。临时节点、显示和选择恢复，几何不变；HIP仍可能dirty，之后保存或重开检查点。

GUI实测暴露setPwd会隐式选中宿主对象，选择应在视图/上下文恢复后最后恢复；已有修复与前后状态核验。宽幅flipbook可能裁切细长斜向构件，透视取景已增加随宽高比变化的保守边距，可能留较多空白。不要仅凭输出PNG存在宣称局部完整；对照所选bbox再看图。

本轮补了折边与回折唇、厚连接体及错位检查；槽钢开口朝向、壁厚/孔距、背面与小倒角仍属推定。完整视图核组合，隔离图核开口与连接，不能只用拓扑通过宣布照片匹配。新hython独立HDA、GUI保存重开和局部视图验证去向见docs/V010-VALIDATION.md。
