# 双层总装：高度联动与封装

适用于照片样段的双站丁字支架、两段风管，以及 `workai::two_tier_snapshot::1.0.*`。这是一份218件的快照HDA，只开放上层高度；其他尺寸沿用已接受几何。它不属于十个生成配方，不用 `upsert_asset_instance` 创建，也不替代后续逐件程序化建模。

## 使用已交付资产

从专项 CURRENT-STATE 找唯一 HIP/HDA，先核连接、当前文件和未保存状态。保留该版文件，再开候选。不要调用历史固定路径修改已经封装的总装。

1. `get_asset_schema(path)` 读取本实例的 `tier_y`、范围和 `assembly`。当前限定450–800mm，默认550mm，单位米；这是视觉样段范围，不是安装标准。
2. `inspect_asset_instance(path)` 核218件、214个固定件、4个移动件、两站承托与四个端接。
3. `set_asset_parameters(path, {"tier_y": 0.58})` 更新。新类型写入后实际cook并检查；失败尝试复位并再检查，复位失败会明确报错。普通节点仍沿用原数值写入语义，不声称全局事务。
4. 用 `preview_asset_views` 查看右视、透视或按名字隔离；需要灯光/材质判断时使用原生渲染。保存另一HIP后重开回读。复制实例以“实例路径＋构件name”标识，不要求不同实例共用全局唯一name。

HDA内存有网格和PythonModule，可脱离仓库src在新场景创建几何；材质网络仍由配套HIP提供。只复制HDA不能宣称外观依赖齐全。内部解锁的资产拒绝按本管理协议更新；保留独立编辑版本。

## 封装时的检查

- `scripts/capture_tier_assembly.py` 将源几何及四个移动件的关系收进同一个HDA，不依赖旧场景的绝对节点路径。所有源对象矩阵先核对，不能直接把非单位矩阵的局部几何混合。
- 合并前把实际生效的对象级材质补到缺失或空的面材质上。六个型钢原本完全没有该属性；本次共186件需要显式继承对象材质。核实际材质节点和渲染，不能仅比字符串存在。
- Houdini字符串属性创建默认值不等于每个primitive都获得该值。显式赋 `name/part_type/shop_materialpath`，经布尔、倒角后再检查；空name立即失败。
- 保留逐件坐标、法线、颜色、连接和有效材质对应。说明属性迁移与形体变化的区别，不把补写材质路径说成几何逐字节无改动。

## 接触与参考图

风管外凸接缝会让整体bbox底部低于实际承托底板。按每个横担的实际X及完整支撑带采样底板；不能使用整个风管最低点判断悬空。前后站都需纳入依赖清单，分别覆盖对应风管段。射线的 `min_hit/max_hit/tolerance` 显式按毫米级间距设置，并用错位、缺件反例验证检查器。

先用照片侧的仰视核红黑管顺序、横担走向和遮挡，再用反面检查被挡住的风管。反面更清楚不代表匹配照片。单张照片缺尺度，机位仅定性比较；不把相机调整或灯光遮挡当作尺寸重建成功。

暗面和过曝会妨碍结构检查。检查灯光可单独保存；检查图通过不等于材质成图通过。下一步灯光/材质流程优先补实际绑定、依赖完整性及固定机位下的A/B比较，未实测的预设不要写成通用最佳参数。
