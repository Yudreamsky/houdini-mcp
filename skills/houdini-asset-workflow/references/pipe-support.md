# 管道连接与支吊架视觉样段

适用：MCP 0.5 的 `pipe_support_sample`，实测宿主 Houdini 20.5.487。具体发布验证查仓库 `docs/V05-VALIDATION.md`；本地实例与证据查专项 CURRENT-STATE，不能把旧 PID 或样段路径当作现场状态。

## 输入和操作

1. `list_procedural_assets` 读取当前 recipe、单位和参数；0.7起同时返回数字类型及结构化组合约束。单位为米，默认值是可调视觉样例，不是照片实测尺寸。用 `preflight_asset_instance` 先合并拟改值与当前参数并检查ready；它不生成几何。
2. `upsert_asset_instance(instance_id="pipe-sample", parameters={...})` 创建/更新一个稳定实例。相同 ID 和参数不应产生第二套模型。更新前先保存工作版本。
3. 数字参数包括 length、diameter、wall、support_pitch、hanger_height、bolt_count、segments。先用 catalog/schema 查边界；组合约束由 recipe 校验。壁厚须小于管径20%，圆周segments须为4的倍数，吊杆高度和支架节距须容得下样段。
4. 改管径时检查实际管壁、法兰外径、螺栓圈、横担宽度和夹箍接触；改长度时检查支架数量、节距及两端覆盖。用 `inspect_asset_instance(path)` 回读实际几何，再看图。
5. `preview_asset_views` 返回 front/right/top/perspective 原生图片；`part_types` 可按检查结果中的类型隔离。GUI临时显隐/过滤会恢复，但可能使场景 dirty；预览后再保存，不通过修改 dirty 标志掩盖状态。

有动画、锁定通道、已解锁 HDA 内容或配方版本变化时，managed update 拒绝静默覆盖。先检查人工编辑，保留原实例；需要迁移时创建新实例做对照。不要通过删除表达式或替换库绕开用户未批准的修改。

## 几何和外观边界

样段包含两个空心管段、一对带真实螺栓孔的法兰、垫片、螺栓/垫圈/螺母、重复槽钢横担、吊杆、夹箍与简化锚板。各实体有固定名称和 part_type，改变长度后存续支架身份不变。

孔槽是实际几何，长孔采用椭圆近似；螺纹未建、夹箍与锚板简化、未补照片背后的吊顶或隐藏节点。当前直接生成分组多边形，尚未宣称 packed instancing 或标准件规格库。需要大量重复或工艺特写时，再以真实样例决定实例化和细化。

检查器核局部尺寸、闭合边、法兰孔拓扑、螺栓穿过法兰和孔隙、夹箍/横担接触及支架覆盖。它不是全场景碰撞检查，不给承载或安装合规结论；对象变换另行返回，尺寸为局部坐标测量。

## 已遇到的具体问题

- HDA 使用纯标准库几何算法作为嵌入 PythonModule，节点内部只调用该模块。用独立 hython、不加入仓库 src 路径重建，才能证明资产不依赖开发环境。
- HDA类型和库名包含配方内容指纹；更新配方不静默替换旧实例。文本先统一换行再计算指纹，避免Windows CRLF造成假版本差异。
- 法兰按环形扇区生成真实孔，扇区交界焊接并省略内部墙面；只数对象或用贴图画孔无法验证这一点。
- 视口窗口与输出PNG宽高比不同时，默认frameBoundingBox可能裁掉侧视图；正交取景需要按输出宽高比重新计算宽度，随后实际看图确认完整。
- 隔离预览删除多边形时若保留游离点，会留下“幽灵点圈”；过滤时同时删未使用点，保留原资产几何。

## 交付

保留 HIP、同目录可独立加载的 HDA、实例参数 JSON 和多视图。HDA默认参数与某个实例当前参数是不同状态，不只复制库就声称保存了当前实例。重开 HIP 对比几何指纹；独立加载 HDA 后应用交付参数，再对比几何。通用跨软件导出和实体材质XPU未在本样段实现。
