# 三管共用支吊架

适用MCP0.9的pipe_rack_sample，Houdini20.5.487。固定三根平行管，沿X延伸、沿Z排列、Y向上；每个支撑位置共用一根横担和两根外侧吊杆，各管独立向下开口U形件。不是把三套单管支架重叠摆放。交付及验证查docs/V09-VALIDATION.md和专项CURRENT-STATE。

新实例明确recipe="pipe_rack_sample"，后续同ID更新可省略。各管外径diameter_i、壁厚wall_i、管底抬高rise_i独立，length/support_pitch/hanger_height等共用。spacing_12/23为水平中心距，第二根Z=0。默认外径0.32/0.25/0.20m、中心距0.60/0.55m、rise为0/0.10/0.02m；全部是示例值。

管底Y=.044+rise_i，中心Y=.044+rise_i+diameter_i/2。rise>0时生成实体简化承托座，零rise直接承在横担上；U形件上弧随管升高，两条腿始终延伸穿过同一横担，垫圈/螺母仍在腹板下侧。不要只平移管子造成悬空，也不要把rise误读为中心标高。

横担左右端随最外侧管径和位置改变；只保留一对外侧吊杆。管径改变时同时检查法兰包络和相邻管：本配方用水平间距>=0.775×两管外径之和+0.04m作保守预检，不因有高差就放宽。实际回读另报三对管/法兰包络净距。高差范围0–0.30m，承托座是视觉简化，不代表施工节点设计。

先看完整端视确认三根、两外吊杆和一横担，再看完整顶视/透视及支架隔离图。回读检查涵盖支架节距/两端覆盖、各管承托、U开口、真实多边形孔净隙和紧固件对位。缺承托座、整体移偏中管、U腿横移错孔这三个实际几何负例均应失败；闭合网格数量不能替代这些关系。

升高一根管时共用横担几何不应变；加长时新增支撑，存续名称保持。零rise到非零rise会增加该管的seat构件，这是明确的拓扑变化。HDA独立嵌入原直管算法，新配方不改变已交付的单管/弯头类型。使用复用验收脚本新增目录，核尺寸修改、复位、重开、独立HDA和实际图片。

尚无任意管数、多层路由、通用碰撞、螺纹/标准型钢节点或承载判断。原照片仅提供组合关系；精确规格仍需图纸或实测。
