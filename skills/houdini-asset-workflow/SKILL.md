# Houdini 资产工作流

使用本 Skill 时先核对实际连接的 Houdini 会话、当前 HIP 与未保存状态。用户只要求分析时不建模。已有制作授权持续完成，不为常规步骤重复请求许可。

## 按任务读取

- 制作或修改管道/法兰/支架样段：读 [样段方法](references/pipe-support.md)。当前 recipe 是完整小样段；不声称已有通用管线布置器或任意 HDA 管理器。
- 制作带水平90°弯头的两段管道：再读 [弯头连接](references/elbow-route.md)，区分中心线半径、入口/出口长度、局部轴和连接检查。
- 制作三根平行管道共用横担：读 [共用支架](references/shared-rack.md)，区分中心距、管底抬高、承托座和共用吊杆，避免三套独立支架重叠。
- 按现场照片细化三管节点：再读 [照片参考变体](references/photo-reference.md)，先分辨可见形体与推定，按构件名聚焦核对，避免把模板配色当作连接形式还原。
- 制作橙色外抱接头独立样件：读 [外抱接头](references/external-coupling.md)，核半壳、凸耳孔、紧固件与贯通空间。
- 将外抱接头接入三管候选：读 [局部装配与继承](references/coupled-rack.md)，核替换范围、逐件指纹及邻件间距；当前只支持固定红管单接头。
- 制作黑管重复接头：同读 [连续管段与重复接头](references/coupled-rack.md#黑管双接头与连续管段)，使用固定双接头配方，核轴向端面与支撑落在哪段管身上。
- 细化照片中的蓝色连接本体：读 [凸部、台阶与孔环](references/blue-body.md)，区分可见外轮廓与推定孔/背面，避免将“不碰撞”当作“确实穿孔”。
- 修改参数前预检、验证MCP升级或打包样段：读 [预检与可复用验收](references/acceptance.md)，复用仓库脚本并单独看图。
- 渲染、预览、取消/续渲：读 [渲染经验](references/rendering.md)。先区分 GUI 几何预览、Mantra 和限定地图 XPU。
- 复用或补充经验：读 [经验记录规则](references/experience.md)。只记录本次明确范围内的经验，不写宿主全局记忆，不自动扩展其他项目规则。

## 共用约定

MCP 承担调用和结果回读；HDA/脚本承担几何与参数关系；Skill 记录选用条件、步骤和排错依据。不要把算法复制成大段提示词，也不要把每个 SOP 都封成一个新工具。

先调用 `ping`、`get_scene_info`，必要时 `get_capabilities`。当前宿主没有发现原生工具时，配置存在不等于接通；可用已配置的本地 MCP SDK stdio 客户端，并明确交付是外部 SDK 验证。不要把普通 Python 直连伪称为原生 MCP 调用。

资产修改前保留可恢复版本。照片主要提供外观和相对关系；参数来源标为图纸/实测/估计，缺尺寸时使用明确标注的视觉样例。推定不能晋级为工程设计事实。

用稳定 instance_id 更新已管理实例，保留零件 name / part_type。0.7起，已有实例省略recipe会自动识别；创建新弯头仍明确选配方。先读结构化组合约束，必要时preflight合并当前参数，检查ready而不是仅看调用成功。预检通过不代替几何验收，写入时再次验证。

取景从完整样段开始，再隔离系统检查；对象数量和闭合网格不能替代实际形体、遮挡及空间覆盖检查。

交付核对实际保存文件与库，保存重开、必要时在无仓库源码的独立进程加载 HDA。输出简明报告：改了什么、实际通过什么、未验证什么、资产和证据入口。源文件指纹不变时可继承既有验收，不重复未变视频或全场景渲染。
