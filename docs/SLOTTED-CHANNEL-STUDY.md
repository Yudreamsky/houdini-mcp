# S1 上方长孔型钢独立样件

2026-09-22。基于用户照片 S1 的可见长孔型钢，先验证单构件。MCP 仍为 **0.16.0 / 22 工具 / 10 配方**；本次没有新增 MCP 工具、受管理配方或修改 Skill 规则。

## 范围与来源

照片显示连续长孔构件；背面完整截面、空间朝向、与 T1 横担的连接及上方建筑宿主仍被遮挡。样件采用开口 C 形、两侧回折唇，具体尺寸与朝向是视觉推定，未声称匹配厂家型号或工程节点。独立验证阶段不把未知连接板和锚栓加入管组。

默认长 1050mm、宽/深 41mm、壁厚 2.5mm、回折唇 8mm；17 个 26×11mm 胶囊形贯穿孔，孔距 60mm，等距居中排列。开口朝局部 -Y、长度沿 Z；普通 Houdini 对象变换可改变方向。边缘 0.18mm、两段轻倒角。所有数值均为可调视觉样例，不是实测值。

## 可复现源码与编辑

- `scripts/slotted_channel_sample.py`：纯 Python 连续网格，孔与折边焊接为单一实体，没有接缝内壁。
- `scripts/build_slotted_channel_study.py`：hython 中建立原生 SOP 收尾、材质和三组相机，验证后保存。输出目录必须是新目录，已存在时拒绝覆盖。
- `tests/test_slotted_channel.py`：四项测试覆盖不同长度/截面、闭合与孔拓扑、独立解析体积、真实平行孔边、坏参数和缺面反例。

```powershell
hython scripts/build_slotted_channel_study.py --output assets/my-channel-study
```

HIP 的 `/obj/S1_channel_study/channel_parameters` 提供八个数字参数；`edge_softening` 控制倒角，`OUT_CHANNEL` 是最终输出。生成源码直接嵌入 Python SOP，交付 HIP 可脱离本仓库重开。它尚未打包成 HDA，也不在 `list_procedural_assets` 中；不要用 `upsert_asset_instance` 冒充已支持的新配方。

## 这次实际发现的经验

长孔腹板加倒角后，普通顶点平均法线使整个平面出现扇形波浪高光。第一轮图片暴露了这个问题，闭合拓扑检查没有发现它。修正为保留非倒角轴对齐大平面的准确面法线，孔壁和倒角继续平滑；几何 SHA 不变，法线单独比较。该处理针对本样件的局部轴对齐平面，不能不加选择地套用到任意曲面。源模型到世界空间的旋转应通过对象变换完成。

采用 E001 核外侧/开口内侧/端部，E006 实际看图后修正法线，E008 通过原接受快照哈希继承未变管组。首轮失真的 HIP、图片及作业记录保存在 `evidence/upper-channel-v01/first-render/`，没有用后续成功覆盖失败证据。

## MCP 缺口与下一步

现有打开、脚本执行、参数读取与渲染流程足够支持当前独立样件，不为一个 SOP 增加包装工具。尚待真实装配案例驱动的能力是：构件局部轴、端点、朝向和已确认宿主的受管理装配关系。通用 Python 执行并不等于已经有该接口。
