## 编辑与复现

通过hython运行 `scripts/upper_tier_candidate.py`，显式指定上轮T-joint-01总装HIP及一个新输出目录。拒绝覆盖已有目录。用源HIP和HDA指纹绑定来源；不修改上轮交付。

```powershell
hython scripts/upper_tier_candidate.py --source assets/upper-frame-v01/T-joint-01/assembly.hip --output assets/my-upper-tier
```

`/obj/upper_duct/visual_parameters` 提供长度、宽度、高度、壁厚、层高、横向中心六项估计参数。初始为2.8m×550mm×240mm、1.2mm壁厚，横担承托面Y=550mm、风管中心Z=100mm。风管边缘0.25mm轻倒角。层高同时驱动上层横担与风管底面。

上层横担长度取已存两根竖杆内侧之间的跨度，截面49×41mm；保留真实胶囊孔与回折唇、0.18mm轻倒角。当前跨度固定于冻结基线；若竖杆位置改变，SOP会拒绝不匹配的跨度，不声称通用自动装配。

新增输出为 `/obj/upper_crossarm/OUT_UPPER_CROSSARM` 和 `/obj/upper_duct/OUT_DUCT`。全部生成逻辑嵌入HIP，重开无需仓库src模块。仍保留基础锁定HDA。

## 验收范围

读取实际网格验证风管实体闭合、内部通道贯通、四壁存在；未倒角壳体体积与独立截面面积公式比对。孔洞贯通不等于缺面：薄壁实体应闭合，而空气通道两端开放。

横担两端用短射线核实接触位置，风管底面与横担顶面用双向射线验证。分别注入横担端头偏移、横向错位、风管悬空、穿入横担和通道堵板反例，确保检查读的是实际形体。

上轮220件几何、法线、颜色、材质路径及对象世界变换保持；仅新增2件，总数222。新件对原管组逐件包围盒证明分离下界，指定的承托/端接属于预期接触，不能混称为无碰撞检查。修改层高和风管宽度后核承托、端接与通道，复位指纹应一致。

本地唯一候选、实际报告及图片见assets/upper-tier-v01/README.md；原生报告、无源码路径独立重开和MCP渲染报告分别存候选目录及evidence/upper-tier-v01。本文件不替代实际验收记录。
