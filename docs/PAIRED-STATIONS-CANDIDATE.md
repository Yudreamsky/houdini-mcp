# 沿管线的前后两处双层支架

2026-09-22。接续已验两段风管及拼缝，完善纵向第二处支撑。保留前景站，把模型中已有后排简化吊挂改为两根连续型钢和上下横担；横担与竖杆均延续用户确认的丁字关系。

## 来源与范围

用户照片支持沿管线存在重复支撑，但透视和遮挡不足以量出精确纵向间距。本轮复用模型已有的前后站位X约±0.6m，间距约1.2m仍是估计；没有从草图推导站数或规范间距。后排采用同型框架是可调整的工作解释，建筑锚固、暗藏角码、节点螺栓与承载设计未补。

本轮不新增一套与旧吊杆重叠的框架：退役后排两根圆吊杆、两块锚板、四枚吊杆螺母共8个占位件；只裁短封闭后排下横担的腹板与两侧折边3件，保留其U形腿孔；新增两根连续型钢和一根上横担3件。

212件保持逐面几何、法线、颜色、面材质路径一致，原对象世界变换/对象材质保持；3件调整、8件退出、3件新增，最终218个唯一命名件。管道、法兰、橡胶垫、前景支架及两段风管几何不改。旧已验HIP/HDA保留。

## 复现和控制

```powershell
hython scripts/paired_stations_candidate.py --source assets/duct-seam-v01/candidate-02/assembly.hip --output assets/my-paired-stations
```

脚本拒绝覆盖已有目录。源HIP/HDA哈希与上轮渲染输入绑定，HDA复制到新交付目录且保持锁定。新增对象rear_upright_0、rear_upright_1、rear_upper_crossarm，最终几何名rear_frame_redside、rear_frame_blackside、rear_upper_crossarm。

后排两根竖杆复用1.05m、49×41mm、17个长孔的连续型钢；新增上横担28孔，下横担沿用已有孔位并裁短两端。站位读取冻结基线的旧吊杆中心，不将当前脚本宣传为可变数量的支架阵列器。

原visual_parameters的tier_y同时驱动风管与前后上横担；接缝section_joint的支撑带检查现读取前后两根实际上横担。这里只更新新候选内部的SOP依赖，不修改MCP工具配置或Skill规则。

## 核验范围

- 后排上下横担两端均核实际接触面；3个新型钢闭合、单连通、正体积，最小面面积为正。
- 下横担3个裁切件闭合，6条U形腿周围96条射线通过，孔旁腹板仍存在。
- 风管前后共40个承托采样通过；两个完整横担支撑带分别落在右段、左段管身，接缝避开两站。检查站数、沿轴覆盖及实际承托，不能以“两个横担对象存在”替代。
- 故意降低/抬高/横移后排上横担、删除第二站检查输入、移开后排竖杆，五个实际几何/覆盖反例被拒绝。
- 接缝移到前后两个支撑站分别被拒绝；层高550→580mm时两站承托和后排端接通过，复位后全体指纹一致。
- 新件对未接触的原件使用逐件AABB分离下界；预期端接/承托独立检查，包围盒检查不作承载结论。
- 保存重开及无仓库src路径的独立hython，核全部输出的几何、法线、名称、材质和世界变换；通过外部SDK stdio做Mantra总装、支架隔离、纵向、顶视及后排承托近景，并逐张看图。
