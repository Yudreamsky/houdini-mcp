## 制作与继承

`scripts/paired_frame_candidate.py`用hython读取显式已存三管HIP和型钢HIP，写入新目录；已存在目录拒绝覆盖。

```powershell
hython scripts/paired_frame_candidate.py --rack assets/all-pads-rack-v01/default-01/finished.hip --channel assets/upper-channel-v01/channel.hip --output assets/my-T-frame
```

保留锁定基础HDA及原OUT_FINISHED，在下游移除前景两根旧吊杆、两块锚板、四枚吊杆螺母；只裁短/闭合该站横担的腹板和两侧折边三个原件，再加入两个分别命名的竖向型钢。

215个原件逐面位置、类型、Cd、顶点法线和面材质路径完全保持，对象世界变换和对象材质保持。3个横担件变化、8个旧占位件移除、2个新型钢加入，候选共220件。前景全部三管、24块橡胶缓冲垫、六片轻倒角法兰和U形件未改；背面另一支撑站继承原简化形式。

主输出是原管组OUT_FRAME_CANDIDATE及两个型钢对象的OUT_PLACED_CHANNEL。各channel_parameters管截面/孔阵列，place_T_joint管底端、研究间隙及截面方向偏移；参数变化后需重验。横担裁切位置来自本次冻结基线，不宣传通用参数化装配器。

MCP仍0.16 / 22工具 / 10配方。新增的是专项制作和验收脚本；运行工具、配置和Skill规则未变。旧inspect_asset_instance只检查基础HDA，不能以它的通过代替本次下游输出验收。

## 实际核验

- 两新型钢均为单闭合17孔实体。两端面误差约0.00006mm（浮点存储量级），小于本视觉检查容差；两侧各32/91个取样点命中对应实际接触面，其余多在C形截面空域。取样不等于完整接触面积或承载结论。
- 裁短的腹板和两侧折边均为单一闭合正体积实体，无零面积面；横担位于两立杆内侧端面之间。
- 三管六条U形腿周围各16条射线，共96条确认穿孔仍可通过；另验证孔旁仍有腹板。不得为缩短横担移动U件或封掉原安装孔。
- 两侧各做真实网格悬空6mm、穿插3mm、横移150mm的反例，六个均被拒绝。竖向移动60mm并复位后，几何/法线/材质指纹一致。
- 新件对其他现有构件保守AABB净距下界约170mm；AABB只在分离时证明下界，重叠时不能据此宣称碰撞。
- 保存重开及无仓库src路径的新hython独立重开，通过215原件与新件指纹、材质、世界变换及交付HDA库路径核对。源三管HIP/HDA和独立型钢HIP哈希不变。
- 外部MCP SDK stdio调用打开、场景回读、Mantra渲染/状态/原生图片；总装、支架隔离、端/顶及端接正反面分别留证。不是宿主原生工具或XPU验收。

本地唯一候选入口为assets/upper-frame-v01/README.md所指T-joint-01/assembly.hip。原生报告在候选目录，独立重开和渲染证据在evidence/upper-frame-v01。旧79项运行测试及4项型钢测试按不变来源继承，本轮未把它们写成重跑。

## 实测经验

1. 用户示意图先确定整体关系，件数仍按用户指定的照片依据；用户明确的丁字端接优先于先前的侧搭接猜测。侧搭接旧目录只作撤回历史，不作为交付证据。
2. Houdini20.5.487的hou.Geometry.intersect默认min_hit=0.01，从面外1mm发射时会漏掉目标面。本次显式使用min_hit=1e-7、max_hit=.004、tolerance=1e-7，回读命中点核面位，并以真实悬空/穿插反例验证。该数值针对米制毫米接触样例，不无尺度推广。
3. HIP部分合并要包含对象内部SOP节点；只匹配对象路径可能得到空容器。路径后缀通配符和OUT_CHANNEL存在检查均在本样例实测。
4. 按构件一次遍历实际顶点形成邻件包围盒，避免逐件克隆整架网格。工程承载和固定方式仍不能由几何检查器给结论。

采用E001核完整端/顶/反向，E005处理旧占位件替换，E008继承不变原件。下一步先从照片识别上层一段连续构件及其所属层，不预设总层数；隐藏连接形式仍需依据。
