# 风管分段与外凸接缝候选

2026-09-22。用户接受上层横担与风管样段后继续制作。本轮选择照片中矩形金属通道可见接缝轮廓作为增量；保持层高及既有支架，替换整段风管壳为两段独立薄壁实体。

## 依据与范围

本地原照片约(100,370)—(510,620)的金属通道可见分段边线和凸缘。它支持“连续通道由分段组成”的外观研究，不能确定标准法兰型号、确切壁厚、法兰投影尺寸或隐藏紧固。当前四边外凸翻边和2mm缝隙是可调视觉解释，密封件、螺栓及施工连接方式未建。

原风管长度、宽度、高度、层高不变。新风管两段各为单一闭合薄壁实体：直段外表面接入局部扩大的端部翻边，内部保持矩形通道；翻边与各自管身一体成网格，不叠加装饰环。两段之间保留可见缝隙，不能据此声称气密或已完成机械固定。

接缝X=-150mm，向外凸12mm、轴向厚3mm、两面间距2mm，边缘倒角0.25mm。全部估计值。横担X约600mm，接缝不压在横担上；当前横担完整宽度落在右段管身。

## 编辑与复现

```powershell
hython scripts/duct_seam_candidate.py --source assets/upper-tier-v01/candidate-03/assembly.hip --output assets/my-duct-seam
```

输出目录必须不存在，源HIP/HDA只读，交付另存库文件。节点 `/obj/upper_duct/section_joint` 的四项参数为seam_x、flange_projection、flange_thickness、seam_gap。总管尺寸仍由visual_parameters控制。超出估计范围、接缝逼近端界或移到当前横担支撑带会报错，避免明显不可用布局。该限制针对固定样段，不是规范间距。

最终输出仍为 `/obj/upper_duct/OUT_DUCT`，逐面名称分别为upper_duct_left和upper_duct_right，类型rectangular_duct_segment，面材质明确绑定/mat/duct_galvanized。基础HDA锁定；局部SOP代码嵌入HIP，不依赖仓库src路径重开。

221个非目标构件几何、法线、颜色、材质路径及世界变换保持；退出原单件风管，加入两段，合计223件。旧单件在已存HIP中实际名称为空，因此退役记录按“输出路径＋实际指纹”定位，未假装按不存在的名字匹配成功。

## 本轮核验

- 两段各为闭合、单连通、正体积实体，Euler=0；翻边四边均以实际射线核对两端面，间距约1.99999mm、YZ外轮廓对齐。
- 未倒角体积与“两个直段薄壁体积＋两片外扩翻边增量”的独立公式比对；最终最小面面积均大于零。
- 轴向9条射线贯通，四壁存在；接缝缝隙是未建密封的视觉间隙，不是封闭气密通道验收。
- 横担20个承托采样点全部对应管底，完整支撑带落在右段。不能用含下凸翻边的整件最小Y当作管身支撑面。
- 实际网格反例：两段重叠、缝隙过大、段间错位、整管悬空、通道堵板，五个均检出。接缝移至X=-350mm再复位指纹一致；移到横担处被参数检查拒绝。
- 保存重开、无src路径独立hython、旧221件继承、新两段名称/材质、交付HDA库绑定分别留证。MCP使用外部SDK stdio，Mantra总装与局部正反/端/全段图逐张复核；没有新XPU或宿主原生工具验收。

本地交付入口assets/duct-seam-v01/README.md；原生报告在候选目录，其他证据在evidence/duct-seam-v01。上轮全场景端/顶和未变下层结果按源HIP/HDA哈希继承；不把未重跑的旧测试写成新测试。

## 实测经验与工具边界

1. Houdini20.5.487中，仅用addAttrib创建字符串属性并传默认字符串，没有实际写入本例新面的字符串值。旧风管name实际为空；显式逐面setAttribValue后，name/part_type/材质路径能通过倒角保留。独立反例复现并证明修复不改变几何/法线。旧upper_tier_candidate.py同步修正，旧已验HIP保持原样。
2. 接口凸缘改变总包围盒，但远离凸缘的承托面不变。改用支撑站的实际射线和完整轴向覆盖；不为消除包围盒误报抬高整根管。
3. 复用E001/E004核端部通道与反向接缝，E008按实际保存来源继承不变域。只记录已发生的本例，不升级成所有连接都必须2mm缝或四边翻边。
