# 第一套隔振法兰轻倒角

2026-09-22。用户指出法兰锐边缺少真实的边缘反光。本轮只处理pipe3第一套的两片法兰外圆端缘，使用1.5mm宽度参数、3段圆弧倒角和局部顶点法线；没有扩展到其他法兰、螺栓孔或密封面。尺寸是视觉样例。

## 交付形式

`scripts/finish_flange_edges.py` 提供本机HOM收尾脚本，在锁定的pipe_rack_isolated HDA之后生成原生SOP链。读取稳定name、管径与实际边坐标动态选择外圆端缘；宽度在flange_edges/bevel_width调整。原HDA及九个配方不改，MCP仍为0.15.0、22工具。此脚本经现有execute_code使用，不冒充新增MCP工具。

成品保存在本地assets/flange-bevel-v02/after.hip；before.hip为同相机、材质、灯光和基础法线的锐边对照。库文件仅是原始基础HDA，倒角层在HIP的SOP链中，尚未封装为新的独立HDA。Python SOP代码嵌入HIP，不依赖仓库脚本执行cook；外部脚本用于搭建与验收。

## 检查和证据

对比第一套两片法兰，其余210件面坐标/类型/Cd不变。原生总装检查、法兰闭合/连通/孔拓扑、孔壁及内圈面不变检查通过；倒角没有改变橡胶垫、螺杆位置或安装轴线。非目标210件顶点法线在前后对照中逐项相同。

验证宽度0.75mm/2mm调整、恢复1.5mm，以及管3径改为.32m、spacing23=.58m后动态取边及复位。宽度零值、超界和布尔输入由搭建函数拒绝；Houdini严格范围参数会钳制超界值，不能用“赋4mm后应该报错”验证运行时错误。运行时Python SOP也检查宽度有效范围。

Mantra对照为1200×900。两图用同一法兰金属材质和面光源，变化为外缘几何和目标法线；并非与上一版不同灯光截图直接比较。原生检查、保存重开、无仓库源码环境重开和实际看图证据位于evidence/flange-bevel-v01。最终报告report-02.json，controls.json、standalone.json、visual-review.json。

## 本轮发现并修正

第一轮仅给目标片创建平滑法线，却把其他构件初始化成逐面法线，造成管道和橡胶垫可见棱面。几何检查仍通过，但图像失败。修复为前后共用基础顶点法线，PolyBevel后只重算目标两片，并逐项核非目标法线一致。废弃图像和失败日志保留assets/flange-bevel-v01，不能作为最终交付。

第一轮收尾验证脚本还误用上次execute_code的局部变量；该调用每次创建独立命名空间。显式重新导入后重开检查通过，无需因此重渲已完成图像。最终第二轮也经过完整重开。

这次说明了两条实际经验：毫米级真实边缘能在面光反射下形成窄高光；新增N属性可能改变整组构件的渲染，即使位置/数量指纹不变也不能直接继承外观验收。应检查实际法线和最终图像，而不是把平滑和倒角当成同一件事。

回退可打开原assets/isolation-rack-v01/default-01/detail-balanced.hip，或在新HIP选base_vertex_normals为显示/渲染输出；保留当前金属材质与灯光时用before.hip对照。原基础资产及源代码不变。剩余两套蓝体、内部密封流道、上方构件和照片级材质仍待完善。
